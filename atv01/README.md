# ATv01 — Calculadora

Este diretório contém o exercício da calculadora com seus testes.

- `calculadora.py`: implementação das operações.
- `test_calculadora.py`: testes unitários usando `pytest`.

Como usar:

```bash
cd atv01\projeto
pytest -v
```

Resumo do código:
- Funções básicas de soma, subtração, multiplicação e divisão.
- Testes verificam comportamento esperado e casos de erro.
