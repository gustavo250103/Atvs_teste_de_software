# Teste de Software

Repositório da disciplina de Teste de Software.

Contém dois exercícios:

- `atv01`: Projeto "calculadora" com testes unitários.
- `atv02`: Exercício de validação/formatacao de CPF com testes `pytest`.

Instruções rápidas:

- Para rodar os testes do `atv02`:

```bash
cd atv02
pytest -v
```

- Para rodar os testes do `atv01` (se houver):

```bash
cd atv01\projeto
pytest -v
```
